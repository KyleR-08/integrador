📖 User Manual — Distributed Mail System

This manual explains how to use the Distributed Mail System developed as part of the 3rd Semester Integrator Project at UIDE. No technical knowledge required.

What is this system?

The Distributed Mail System is a web application that allows users to securely register and log in, and then manage their email accounts — including Gmail and Outlook — from a single interface. The system is made up of two services that work together:

Auth Service — Port 8000

Handles user registration and login. Passwords are protected using AES-CBC encryption before being stored.

Mail Service — Port 8080

Handles email management. Connect your Gmail or Outlook account, view your inbox, send emails, and search messages.

Getting Started

Step 1 — Access the Authentication Service

1Open your browser and go to http://localhost:8000/docs

You will see the API documentation with two available actions: /register and /login.

Step 2 — Register a new user

2Click on POST /register → Try it out

Enter your desired username and password in JSON format:

{ "username": "yourname", "password": "yourpassword" }

Click Execute. A successful response returns your new user ID.

Your password is never stored as plain text. The system encrypts it using AES-CBC before saving it to the database.

Step 3 — Log in

3Click on POST /login → Try it out

Enter the same username and password you registered with. A successful response confirms your login.

Using the Mail Manager

Step 4 — Open the Mail Manager

4Go to http://localhost:8080

You will see the main interface showing your registered accounts, inbox, search bar, and email composer.

Step 5 — Connect your email account

5Click + Agregar cuenta to add a new account

Enter your email address and display name. Then click Conectar Gmail or Conectar Outlook / UIDE to authorize access via OAuth2. You will be redirected to Google or Microsoft to grant permission.

OAuth2 means the system never stores your Gmail or Outlook password. You authorize access directly through Google or Microsoft.

Step 6 — View your inbox

6Click Ver bandeja to load your inbox

Your most recent emails appear with sender, subject, date, and a preview of the message body.

Step 7 — Send an email

7Scroll down to Enviar correo

Fill in the Para (recipient), Asunto (subject), and Mensaje (body) fields. Click Enviar to send.

Step 8 — Search emails

8Use the Buscar correos search bar

Type any keyword and click Buscar to search through your emails.

Make sure both services are running via docker compose up before accessing the system.

Switching between accounts

If you have multiple accounts registered, click Activar next to the account you want to use. The active account is shown at the top and marked with a green badge.
